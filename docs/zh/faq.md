# 常见问题

## 安装与更新

### 我要装哪些 skill？

只装你要的平台 collector。要做 App 评论报告，再加 `app-reviews-analyst`。
要业务分析（VOC、Upwork 接单），再装对应的业务 skill。
全套清单见 [5 分钟上手](getting-started.md#1-安装-skill)。

### 装完怎么升级？

重新发一次安装指令即可，AI 会覆盖到 `~/.monsterget/skills/<skill>/`。
collector 也可以运行自己的 `update-skill.sh` 检查新版本。

### 怎么卸载？

删除对应目录：`~/.monsterget/skills/<skill>/`。
共享的 `~/.monsterget/state.json` / `version.json` 可以保留，其他 skill 还在用。

## 第一次设置

### 为什么一定要装扩展 + 登录？

因为采集在你自己的浏览器里跑，用的是你的真实登录会话。没有扩展就无法在页面里取数；没有登录就拿不到需要登录的页面。

### 可以只登录 TikTok，不登录 monsterget.com 吗？

不行。monsterget.com 用来下发任务和回传结果；TikTok 登录用来让页面正常显示。

### App Store / Google Play 评论要登录商店吗？

不需要。评论是公开数据，只要扩展 + monsterget.com 登录即可。

### 我换了浏览器怎么办？

三件事必须重新在同一个浏览器里做：装扩展、登录 monsterget.com、登录目标平台。

## Quick / Standard / Deep 有什么区别

| 档位 | 用途 | 结论强度 | 时间 |
|---|---|---|---|
| Quick | 先看有没有信号、演示 | 方向性，不能写进决策 | 3–5 分钟 |
| Standard | 正常业务报告 | 可写进报告/周会 | 8–20 分钟 |
| Deep | 竞品、多市场、高 stakes | 更稳，但仍不是全量 | 30–60 分钟 |

典型量级（默认值，可按需调整）：

| 平台 | Quick | Standard | Deep |
|---|---|---|---|
| App 评论 | 100–200/商店 | 500–1,000/商店 | 2,000+/商店 |
| TikTok | 50–100 视频 / 100–200 评论 | 300–500 视频 / 500–1,000 评论 | 1,000+ |
| X | 100 推文 / 200 评论 | 500 推文 / 1,000 评论 | 2,000+ |
| LinkedIn | 50 岗位 / 20 档案 | 200 岗位 / 100 档案 | 500 / 300 |
| Upwork | 30–50 岗位 | 100–200 岗位 | 300–500 |

> Quick 必须被明确标注为"小样"。如果有人把 Quick 叫"完整报告"，让他改。

## 报告与数据

### 报告里的数字可信吗？

数字来自 `metrics.json`，由 Python 从 CSV 计算，同一份 CSV 重跑结果一致。
但"数字可复现"不等于"结论一定对"：样本、词典、时间窗都有边界。

### 为什么报告说 Confidence 是 Low？

常见原因：样本太少、只有一个来源、时间窗太窄、数据太旧、缺一个平台。
Low 只能当方向性参考，不要写进正式决策。

### 为什么两个平台不能直接比条数？

iOS 和 Android 的评论总量、评分分布、用户结构都不同。
只能比"各自组内的占比"，不能把条数相加。

### 报告里的原话为什么带 `[链接已隐去]`？

报告默认清洗邮箱、URL、@handle、电话号码，避免泄露个人信息。
原始 CSV 里仍然是公开页面上的原文。

### 我想改时间窗 / 加竞品，要重抓吗？

- 改时间窗、评分筛选、分段、Top N、语言：通常不用重抓。
- 加竞品、加关键词、加国家、扩样本：要补抓，AI 应先报次数和时长。

## 失败排查

### 浏览器没打开 / 没反应

1. 扩展装了吗？装在你告诉 AI 的那个浏览器里吗？
2. monsterget.com 登录了吗？
3. 目标平台登录了吗？
4. 浏览器窗口是不是被其他窗口完全遮住了？

### 一直显示排队 / `not_found`

通常是任务没被扩展认领：检查扩展是否启用、是否在正确的浏览器、页面是否正常打开。
让 AI 按失败清单逐项确认，不要自己反复重试。

### 抓到 0 条

- 链接/关键词是否正确？
- 换一个更宽的关键词或另一个国家/语言。
- 有些内容本来就没有公开数据（私密账号、已删除、地区限制）。
- 不要用"换个词偷偷重试"掩盖失败；让 AI 说明原因。

### 报告没生成

- 需要 Python 3.10+（macOS/Linux 一般自带；Windows 装 Python 或 `py`）。
- CSV 列名是否包含评分/正文/时间？缺列会报错，不会填 0。
- 样本是否低于最小门槛（默认 50 条）？

### 只有部分数据

报告会在 Coverage 里写缺失。不要把它当成全量结论；可以补抓或降低结论强度。

## 能力边界

### 支持哪些平台？

TikTok、X、LinkedIn（档案/岗位/人员）、Upwork、App Store、Google Play。
共 22 个 Agent API 爬虫。

### 为什么 Instagram 做不了？

站点有 Instagram 采集器，但目前没有暴露给 Agent API。skill 不会假装能跑。

### 能做视频字幕/逐字稿分析吗？

不能。没有字幕/转写字段。只能分析描述、标题、评论等文本。

### 能做广告库/投放素材分析吗？

不能。没有广告库数据。

### 能做受众年龄/性别/收入画像吗？

不能。没有人口属性数据；评论者代理指标也只能做低置信度参考。

### 能做 LinkedIn 公司完整组织架构吗？

公司员工列表是 devOnly。以公开岗位 + 人员搜索 + 档案为主。

## 隐私与合规

### 数据会上传到服务器吗？

采集在你浏览器里完成；服务器只做任务结果临时中转，取走即删，最长 24 小时。
CSV 和分析结果保存在你本机。

### 报告会显示用户名/头像吗？

默认不显示，并对邮箱、URL、@handle、电话做清洗。

### 批量采集会封号吗？

有可能。采集使用你自己的账号，批量采集可能违反平台 ToS。
控制频率、不要采集私密内容、不要用于骚扰或出售名单。

### 可以把数据卖给客户吗？

只能交付聚合分析结果和脱敏原话；不要交付个人名单、联系方式或可识别个人信息。
具体红线见 [数据与隐私](data-and-privacy.md)。
